# 词性小剧场 · Word Theater

一个给小学生（3–6 年级）玩的英语**词性**互动闯关游戏：名词、动词、形容词、副词，四个角色各守一个岗位，玩着玩着就会区分了。

🎮 **在线玩**：https://weiyinerzui.github.io/word-theater/

手机竖屏体验最佳，支持触屏与键盘（1–4 键快速选岗位，Esc 关闭弹层）。

---

## 为什么这样设计

按**认知负荷理论（Cognitive Load Theory）**和**交替实例原则（Interleaved Practice / Varied Examples）**设计：

| 原则 | 在游戏里的落地 |
|---|---|
| 降低外在负荷 | 全游戏只有**一种操作**：先点单词 → 再点岗位。8 个关卡操作完全一致，孩子只需学一次。 |
| 控制内在负荷 | **一次只加一个新词性**：第 1 关只有名词/动词，第 2 关加形容词，第 3 关加副词。每关开头先"认识新角色"，旧角色以小徽章复现。 |
| 增加相关负荷 | 每个岗位都配一个**判断问题**（它是名字吗？它在做动作吗？什么样的？怎样地做？），把"背结论"变成"用问题推理"。 |
| 交替实例 | 同样的判断，换不同的词、不同的场景、不同的题型反复练（分类 → 解剖句子 → 拼句子），避免"只会这几个词"。 |
| 渐隐式支架 | 同一个词错两次，自动亮出**岗位徽章 + 目标高亮**，把失败变成提示；做对了才让它消失。 |
| 易混对照 | 第 4 关专攻"长得像别认错"：`happily / happy`、`slowly / slow` 这类 -ly 陷阱，成对比较。 |
| 及时反馈+低风险 | 错了不扣分、只给**怎么想**的提示；第 8 关才有 3 颗心，用完可以原地重挑。 |

## 八个关卡

1. **名字还是动作** —— 名词 vs 动词
2. **什么样的东西** —— 加入形容词
3. **怎样地做** —— 加入副词
4. **长得像别认错** —— 易混词对照（-ly 副词 / 形容词 / 名词）
5. **四个岗位全到齐** —— 四个词性混合分类
6. **按岗位拼句子** —— `a cute rabbit` / `The little turtle walks slowly.`
7. **句子大解剖** —— 给真实句子里的每个词找岗位，功能词（the / two）灰色不可点
8. **终极舞台** —— 混合题型 + 3 颗心

## 文件结构

```
index.html        ← 单文件成品（CSS/JS 已内联，可直接打开或部署）
build.py          ← 由 src/ 生成单文件 index.html
src/index.html    ← 源码：结构
src/style.css     ← 源码：设计令牌 + 视觉编码（名词橙 / 动词绿 / 形容词蓝 / 副词紫）
src/app.js        ← 源码：关卡数据、四种题型、进度存档
tests/            ← Playwright 冒烟测试（自动通关 1–8 关、爱心失败路径、多分辨率截图）
```

改完源码后跑：

```bash
python3 build.py                    # 重新打包单文件
python3 tests/test_auto.py shots    # 自动通关 + 截图，检查 console 报错
```

## 技术要点

- 零依赖、零构建工具，纯 HTML/CSS/JS，单文件 72 KB。
- 音效用 WebAudio 现场合成，英文发音用浏览器 `speechSynthesis`（en-US），无外部资源。
- 进度存 `localStorage`（键 `wordTheater.v1`）：星星、通关记录、名字、音效开关。
- 响应式：手机竖屏 / 平板 / 电脑均可，支持 `prefers-reduced-motion`。
- 家长设置里有"解锁全部关卡"（老师演示用）和"清空进度"。
